# طيف ستوديو — Tayf Studio

مشغّل وسائط مكتبي عربي أولاً، مبني على Electron وReact، مع أدوات فيديو مدمجة (GIF، قص، تحويل، دمج، لقطات) وطبقة توافق تلقائية تعتمد على FFmpeg لتشغيل الصيغ التي لا يدعمها Chromium أصلاً.

> المشروع مستوحى من **مجموعة وظائف** QQPlayer بعد تحليل ثابت للنسخة المثبّتة محلياً. لا يحتوي على أي كود أو أصول أو موارد من QQPlayer، وهو تنفيذ مستقل مرخّص تحت GPL-3.0.
>
> **المطور: خليفة القدسي (Khalifa Al-Qudsi)**

## المزايا

### التشغيل
- فيديو وصوت وصور، مع واجهة عربية RTL كاملة، وعند اختيار الإنجليزية تتحول الواجهة **كلها** إلى LTR كتصميم (القوائم، اللوحة الجانبية، النوافذ، الاتجاهات، والمنزلقات) وليس ترجمة فقط.
- تشغيل أصلي سريع لصيغ Chromium (MP4/H.264، WebM، MP3، AAC، FLAC، Opus، WAV…).
- **فتح رابط** (Open URL): تشغيل وسائط مباشرة من http/https — مع سجل روابط قابل للمسح، ودعم الملفات العادية (MP4/MKV/MP3…)، وبث HLS (`.m3u8`) يُحوَّل تلقائياً عبر FFmpeg، ورفض آمن للبث المباشر بلا مدة معروفة.
- أزرار **إرجاع/تقديم** (تأخير/تقديم) في شريط التحكم مع مقدار قابل للضبط (5/10/30 ثانية) وتنعكس على مفتاحي الأسهم.
- **خطوة إطار** للخلف/للأمام (`,` و`.`) وسرعة تشغيل من 0.5× إلى 2× مع خيار «تطبيق السرعة الحالية دائماً».
- **توافق تلقائي**: عند فشل التشغيل المباشر (MKV، AVI، WMV، FLV، RMVB، TS، MPEG-2، WMA، APE…)، يبدأ ffmpeg بنسخ المسارات المتوافقة أو إعادة ترميزها إلى MP4/M4A مؤقت، ثم يستأنف التشغيل تلقائياً مع شريط تقدّم وإمكانية الإلغاء.
- تخزين مؤقت للنسخ المتوافقة في `%TEMP%\tayf-cache` لمدة 14 يوماً، فلا يتكرر الانتظار عند إعادة فتح الملف.
- استئناف موضع التشغيل السابق لكل ملف، وسجل ملفات حديثة قابل للبحث.
- قائمة تشغيل (فتح ملف/مجلد، إضافة للمجلد الحالي، إزالة، تفريغ، ترتيب طبيعي للأسماء).

### الترجمة
- تحميل SRT / VTT / ASS / SSA / SUB.
- اكتشاف تلقائي للترجمة المجاورة للفيديو واختيار الأفضل.
- كشف ترميز ذكي: UTF-8/UTF-16 وWindows-1256 للعربية وترميزات CJK الشائعة.
- تعديل التأخير أثناء التشغيل، تغيير حجم الخط، إخفاء/إظهار، وإفلات ملف ترجمة على الفيديو.

### الأدوات (FFmpeg)
- **GIF**: من مقطع محدد مع fps وعرض ونظام ألوان محسّن.
- **قص المقطع**: نسخ مباشر بدون إعادة ترميز أو ترميز H.264 بجودة قابلة للضبط.
- **تحويل الصيغ**: MP4 / MKV / WebM / MP3 / WAV / FLAC / GIF / PNG / JPG.
- **دمج الفيديو**: عدة ملفات مع إعادة الترتيب، نسخ سريع أو إعادة ترميز.
- **معلومات الوسائط**: المدة، البتريت، الأبعاد، الترميزات، الصوت، المسارات.

### الواجهة والنوافذ
- شريط عنوان مخصص (بدون إطار) مع قوائم ملف/تشغيل/أدوات.
- نمط مصغّر دائماً فوق النوافذ، وتثبيت، وملء الشاشة، واستعادة الأبعاد.
- لقطات شاشة PNG من الفيديو مع مجلد حفظ قابل للتخصيص.
- سمة فاتحة/داكنة، لون تمييز، وحفظ الإعدادات تلقائياً.
- سحب وإفلات الوسائط أو الترجمات، وفتح الملفات من سطر الأوامر/مستكشف الملفات.

## التشغيل والبناء

المتطلبات: Node.js 18+ وWindows (تم اختبار Windows 10/11 x64).

```bash
npm install
npm run dev        # تشغيل التطوير
npm run typecheck  # فحص TypeScript
npm run build:dir  # بناء غير حزمي للاختبار في release/win-unpacked
npm run build      # إنشاء مثبّت NSIS في release/
```

- **FFmpeg مرفق** في الحزمة الجاهزة (`resources/bin/ffmpeg.exe`، إصدار 6.1.1 essentials من gyan.dev). ملف ffmpeg غير مرفوع إلى مستودع الكود — عند البناء من المصدر ضع `ffmpeg.exe` في `resources/bin/` (أو عيّن `TAYF_FFMPEG` إلى مسار ffmpeg).
- لتجاوز المسار المرفق: عيّن متغير البيئة `TAYF_FFMPEG` إلى `ffmpeg.exe`.
- الأدوات وطبقة التوافق تحتاج FFmpeg؛ التشغيل الأصلي للصيغ المدعومة يعمل بدونه، وتظهر رسالة واضحة عند غيابه.

### بنية المشروع

```
src/
  main/
    index.ts       نافذة Electron، بروتوكول tayf:// مع دعم Range، IPC، دورة حياة التطبيق
    ffmpeg.ts      اكتشاف FFmpeg، probe عبر stderr، أوامر الأدوات، التقدّم والإلغاء
    compat.ts      طبقة التوافق: نسخ/ترميز مؤقت مع تخزين مؤقت
    subtitles.ts   كشف الترميز، قراءة الترجمات، البحث بجانب الفيديو
    store.ts       إعدادات/حديثة/مواضع الاستئناف بكتابة ذرّية
  preload/index.ts واجهة API آمنة عبر contextBridge
  shared/types.ts  الأنواع المشتركة وعقد TayfAPI
  renderer/        React 18 + Tailwind: App، Player، Controls، Playlist، TitleBar، Settings، ToolModals
resources/bin/     FFmpeg المرفق
build/icon.ico     أيقونة التطبيق (16–256 بكسل) المستخدمة في الملف التنفيذي والمثبّت
analysis/          مخرجات تحليل QQPlayer الثابت محلياً فقط — غير منشورة في المستودع العام
```

- بروتوكول الوسائط: `tayf://local/?p=<encoded absolute path>`، ويدعم `Range`/`206` و`HEAD` ورؤوس CORS لتتيح لقطات الشاشة عبر canvas.
- تُحفظ البيانات في `%APPDATA%/tayf-studio/` (إعدادات، سجل، مواضع).
- الإصدار: Electron 32، React 18، Tailwind 3، electron-vite 3، electron-builder 25.

## تحليل QQPlayer (مرجع التصميم)

تم تحليل نسخة QQPlayer المثبّتة محلياً (`C:\Program Files (x86)\Tencent\QQPlayer`، الإصدار 4.6.3.1104) تحليلاً **ثابتاً بدون تشغيل**، عبر فحص موارد PE، واستخراج السلاسل النصية، وفك حزمة الموارد `RDB` بأداة مخصصة.

- بصمة `QQPlayer.exe`: `9FFE2EE8C28ECD306328D61092CCA5270C2C6F73B37C75D51C4F83D56BF02F56`
- بصمة `QQPlayerMainModule.dll`: تبدأ بـ `1CBD9337…438F50`
- Evidence من فحص موارد PE: `ev_873722fd7bc76dd04c1ed4ade156ccded268fe5a11e433d0841ad76fcdaa7d37`
- استُخرجت **1122** ملفاً من حزمة `RDB` إلى `analysis/rdb_extracted/` (منها واجهات Xtml، أيقونات، سمات، وأصول I18N)، دون بايتات غير مغطاة.
- السلاسل النصية الكاملة في `analysis/strings/`، ومنها:
  - `s.video.qq.com/subtitle_search?query=` (بحث ترجمات أونلاين)
  - `vv.video.qq.com/getvinfo|getvkey|getvbkey|checktime` و`vd.l.qq.com/proxyhttp` (بث/تحقق)
  - `dldir1.qq.com/qqyy/pc/config/config.ini` (تحديث الإعدادات)
- سمات النسخة: مشغّل أساسي، قائمة تشغيل، مفضلة، ترجمات، مولّد GIF، قص فيديو، محوّل صيغ، دمج فيديو، لقطات، سمات، مشاركة، معلومات وسائط، إعدادات، مركز تحديث، تأثيرات صوت/صورة.

الخلاصة: أُعيد بناء **الوظائف** فقط بصياغة مستقلة، مع استبدال الخدمات السحابية الخاصة بـTencent (البحث عن الترجمة/البث) بميزات محلية، والاعتماد على FFmpeg بدلاً من محرّك QLPlayer المملوك.

تفاصيل إضافية في `analysis/` (السكربتات: `extract_strings.py`، `rdb_extract.py`).

## حدود معروفة

- توافق الصيغ يعتمد على Chromium + FFmpeg؛ ملفات HEVC/HDR قد تحتاج إعادة ترميز أو عرضاً غير مثالي للألوان.
- النسخ المتوافق للفيديو الطويل قد يستغرق وقتاً (يظهر تقدّم ويمكن الإلغاء).
- لا يوجد DRM أو وصول لواجهات Tencent الخاصة (البحث عن الترجمة/البث)؛ تشغيل الروابط يتم عبر http/https عادي ويحترم الروابط العامة فقط.
- روابط http غير المشفرة قد تتقطع في بعض الشبكات؛ يُفضّل https.
- القص بوضع «نسخ المسارات» سريع لكنه يبدأ عند أقرب إطار مفتاحي؛ للحصول على دقة إطارية استخدم إعادة الترميز.
- الترجمة تُعرض كنص مبسّط (لا تنسيق ASS الغني بالكامل).
